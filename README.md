# homebrew-omnideck

Official Homebrew tap for the [Omnideck](https://github.com/omnideck-dev/cli) CLI tool.

## Install

```sh
brew install omnideck-dev/tap/omnideck
```

## Usage

```sh
omnideck
omnideck --help
```

## Updating

```sh
brew upgrade omnideck
```

See the public [Omnideck Roadmap](https://github.com/orgs/omnideck-dev/projects/1) board for what's planned, in progress, and recently shipped.
